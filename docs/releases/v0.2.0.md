Prepare this tag after the Sprint 5 docs and security review are on the commit you want to release. A person cuts the tag. Do not tag from an agent session that still has uncommitted Sprint 5 work.

S5-T17 is green. The journey is `e2e/tests/sprint5.api.test.ts`. The checklist is [../security/s5-review.md](../security/s5-review.md). Do not cut this tag if that review is missing or the journey fails.

## What the tag means

A self-hoster can install Marketing OS, connect the mock source, enable `ask_marketing`, `specialist_config`, and `managed_work`, run the weekly performance review as configuration, publish the example Linear policy, and take one `create_issue` through approval to a stored outcome. Replay does not create a second issue. Other tenants get 404 on approvals and recommendations. Audit payloads have no access token and no prompt body. The same code path runs for `MOS_DEPLOYMENT_MODE=self_hosted` and `cloud`.

Flags stay **false** in `supabase/migrations` and in `packages/core/src/flags.ts`. Enabling them is an operator step, documented in [../self-hosting.md](../self-hosting.md).

## Not in this tag

Paid-media writes. Unattended autonomy. Linear OAuth token exchange. A customer-facing workflow builder. Credit checkout. Live Linear network calls from unit tests. Published schedules firing in production (cron does not call `tickSchedule` yet).
