# v0.1.0-alpha

Prepare this tag after the Sprint 3 docs are on the commit you want to release. A person cuts the tag. Do not tag from an agent session.

## What the tag means

A self-hoster can install Marketing OS, connect the mock source, enable `ask_marketing`, and ask one question. The answer shows a number taken from synced metrics and the evidence for that number.

`ask_marketing` stays **false** in `supabase/migrations` and in `packages/core/src/flags.ts`. Enabling it is an operator step, documented in [../ask-marketing.md](../ask-marketing.md).

## Not in this tag

Live model calls are not required for the exit test. Text-to-SQL, campaign and channel breakouts, recommendations, credits, and customer-edited prompts are out of scope. Staging smoke is S3-T37.

## Tag

From a clean `main` that contains this release:

```bash
git status
git tag -a v0.1.0-alpha -m "Marketing OS v0.1.0-alpha: Ask Marketing on synced metrics"
git push origin v0.1.0-alpha
```

Do not force-push the tag. If the tag already exists, stop and pick a new name.

## After the tag

```bash
pnpm test
pnpm test:e2e
pnpm eval:ask
```

Replay must be 31 passed, 0 failed. Then follow [../ask-marketing.md](../ask-marketing.md) on a fresh local database with either an OpenRouter key or Ollama.
